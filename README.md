# هور — Landing Page

لندینگ‌پیج رسمی اپلیکیشن **هور** (همراه آموزشی مسیر بارداری) — کاملاً راست‌به‌چپ، ریسپانسیو و بدون هیچ وابستگی خارجی (فونت، ویدیو و تصاویر همگی خودمیزبان هستند).

## مشاهده آنلاین

بعد از فعال‌سازی GitHub Pages:

```
https://soheilsss11.github.io/hoor/
```

## ساختار پروژه

```
index.html                 صفحه اصلی لندینگ
site.webmanifest           مانیفست PWA
assets/
├── css/style.css          سیستم طراحی کامل (پالت رسمی هور)
├── js/main.js             تعامل‌ها: منو، اسلایدرها، شمارنده، آکاردئون، ویدیو، ...
├── fonts/                 فونت وزیرمتن — نسخه اعداد فارسی (خودمیزبان woff2)
├── img/                   تصاویر تولیدشده (هیرو، آیکون‌های سه‌بعدی، آواتارها)
├── media/                 ویدیوی معرفی (دانلودشده از آپارات) + پوستر
└── favicon.svg            فاوآیکن
```

## بخش‌های لندینگ

- هیرو با موکاپ زندهٔ اپ (ساخته‌شده با HTML/CSS خالص) + کارت‌های شناور پارالکس
- نوار اعتماد متحرک (Marquee)
- آمار با شمارندهٔ اعداد فارسی
- امکانات (۶ کارت با آیکون‌های سه‌بعدی اختصاصی)
- مسیر بارداری در سه سه‌ماهه
- اسلایدر نمایش صفحات اپ
- ویدیوی معرفی (پخش‌کننده سفارشی روی ویدیوی میزبان‌شده در ریپو)
- نظرات مادران (اسلایدر لمسی RTL)
- دانلود از کافه‌بازار / مایکت / فایل مستقیم
- سوالات متداول (آکاردئون انیمیشنی)
- CTA، فوتر کامل، دکمه بازگشت به بالا، نوار پیشرفت اسکرول

## فعال‌سازی GitHub Pages

Settings → Pages → Build and deployment → **Deploy from a branch** →
شاخهٔ جاری را انتخاب و پوشهٔ **/ (root)** را ذخیره کنید.
